# Marriage Garden Website Demos

Five complete, themed demo websites for one fictional wedding venue (Utsav Garden & Banquets, Ring Road, Indore) — built with Next.js 14 + Tailwind.

- `/` — showcase landing (pick a design)
- `/heritage` Classic Royal · `/shimmer` Modern Animated · `/haldi` Warm Festive · `/velvet` Dark Luxury · `/ivory` Minimal Editorial
- Each theme: Home, About, Venues, Services, Gallery, Contact + date-availability WhatsApp enquiry (native date picker, event type, guest count, venue), Hindi/English toggle

**Rebrand for a client:** edit `lib/config.ts` (name, city, phone, WhatsApp, map).

```bash
npm install
npm run dev
```
